
# 🎮 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input. The program will choose a random word, let the player guess letters, and track progress until the word is solved or the player runs out of attempts.

## 📝 Tasks

### 🛠️ Task 1: Set up the game

#### Description
Create a game that picks a random word from a list and displays blanks for each letter.

#### Requirements
Completed program should:

- store a list of words
- choose one word at random
- display underscores or blanks for each letter
- keep track of guessed letters

### 🛠️ Task 2: Handle player input

#### Description
Allow the player to enter one letter at a time and update the game state based on the guess.

#### Requirements
Completed program should:

- accept user input for a single letter
- check whether the letter is in the hidden word
- reveal matching letters in the correct positions
- prevent duplicate guesses
- show the remaining attempts after wrong guesses

### 🛠️ Task 3: Finish the game

#### Description
Define the win and lose conditions and show a clear final message to the player.

#### Requirements
Completed program should:

- end when the word is fully guessed
- end when the player runs out of attempts
- display a win or lose message
- show the hidden word at the end of the game
